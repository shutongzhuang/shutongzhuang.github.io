# Shutong Zhuang — Physics to AI

Personal research website: https://shutongzhuang.github.io/

An English homepage and study-notes library, adapted from the existing public website.

## Content

- `index.html`: research introduction, selected AI work, physics preprints, and contact.
- `notes.html`: learning notes, full tables of contents, and citation text.
- `styles.css`: shared layout and responsive styles.
- `site.js`: contents controls and citation copying.
- `star-sea.webp`: the existing website’s star-sea header artwork.
- `icon.svg`: website icon.
- `.nojekyll`: serve these static files directly through GitHub Pages.

The PDF links point to the existing shared notes. The research survey is described as an unpublished manuscript and is not included for download.

## Updating

Edit the corresponding HTML file on GitHub and commit the change. GitHub Pages publishes the latest `main` branch from the repository root.

The website uses plain HTML, CSS, and JavaScript, with no package installation or build step.
